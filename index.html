Sistema de análisis postural con IA — ESPE 2025

Términos de uso

1. Cámara: Se requiere acceso a tu cámara web. Las imágenes se procesan localmente en tu dispositivo — no se envían a ningún servidor.

2. Privacidad: No se almacenan imágenes ni videos. Solo se procesan coordenadas numéricas de tus articulaciones.

3. Datos: Las sesiones se registran en Supabase con fines académicos anonimizados (proyecto de tesis ESPE).

4. Notificaciones: Si configuras Telegram (opcional), recibirás alertas cuando se detecte mala postura prolongada.

5. Limitación: Esta herramienta es de asistencia académica. No reemplaza consejo médico profesional.
