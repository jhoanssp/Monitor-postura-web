Monitor de Posturas Web

Analisis postural en tiempo real mediante Inteligencia Artificial

Deteccion en tiempo real

Usa tu camara web para analizar tu postura mientras trabajas o estudias. Todo el procesamiento ocurre localmente en tu dispositivo.

Modelos entrenados con datos reales

Clasifica 5 posiciones distintas usando Random Forest con ~98% de precision. Dos modelos: frontal y lateral.

Alertas por Telegram

Recibe notificaciones cuando mantengas mala postura mas de 20 segundos y un resumen al finalizar cada sesion.

Datos para investigacion

Tus sesiones contribuyen a un dataset anonimizado de posturas que apoya investigacion academica sobre ergonomia.

Terminos de uso

1. Acceso a camara: La aplicacion solicita permiso para acceder a tu camara web. Las imagenes se procesan unicamente en tu navegador y nunca se transmiten a servidores externos.

2. Privacidad de datos: No se almacenan imagenes ni videos. El analisis trabaja exclusivamente con coordenadas numericas (x, y, z) de 33 puntos de tu cuerpo detectados por MediaPipe.

3. Dataset academico: Las coordenadas de postura se guardan de forma anonimizada en una base de datos para enriquecer un dataset de investigacion sobre ergonomia postural. Tu usuario es un UUID anonimo sin datos personales.

4. Notificaciones Telegram: Si decides conectar Telegram, los mensajes se envian directamente desde tu navegador a la API oficial. Solo tu Chat ID se guarda en tu dispositivo (localStorage). El bot ya esta configurado — no necesitas ningun token.

5. Uso responsable: Esta herramienta es un asistente de bienestar postural. No constituye diagnostico medico ni reemplaza la evaluacion de un profesional de salud.
