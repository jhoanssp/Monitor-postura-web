Privacidad total

No se graba video. No se envían imágenes a ningún servidor. Solo se procesan coordenadas numéricas de tus articulaciones.

¿Para qué sirve?

Esta herramienta está diseñada para ayudarte a mantener una postura saludable durante largas jornadas frente al computador, reduciendo el riesgo de dolores de cuello, espalda y hombros asociados al trabajo sedentario.

📋

Términos de uso

1. Acceso a cámara: La aplicación solicita permiso para acceder a tu cámara web. Las imágenes se procesan únicamente en tu navegador y nunca se transmiten a servidores externos.

2. Privacidad de datos: No se almacenan imágenes, videos ni grabaciones. El análisis trabaja exclusivamente con coordenadas numéricas (x, y, z) de 33 puntos de tu cuerpo detectados por MediaPipe.

3. Notificaciones Telegram: Si decides conectar Telegram, los mensajes se envían directamente desde tu navegador a la API oficial de Telegram. El token y Chat ID se guardan solo en tu dispositivo (localStorage).

4. Uso responsable: Esta herramienta es un asistente de bienestar postural. No constituye diagnóstico médico ni reemplaza la evaluación de un profesional de salud.

5. Código abierto: Esta aplicación es de uso educativo y personal. El modelo de IA fue entrenado con datos propios y no contiene información de terceros.
